Maquette du rapport d'activité

Maquette du site web du rapport d'activité, réalisée pendant mon stage au CTI Saint-Étienne.

  • HTML
  • CSS
  • JavaScript
Voir le code de la maquette

Les noms et les chiffres de cette maquette sont volontairement masqués (« XXX »).

Le contexte

Pendant mon stage de développement web au CTI Saint-Étienne (mai – juin 2026), j'ai créé le site web du rapport d'activité 2025. Cette maquette est une version de démonstration, construite à partir des données du rapport d'activité 2016 : les noms, les chiffres et les coordonnées y sont remplacés par des « XXX ».

Ce que contient la page

  • une page d'accueil avec le titre du rapport ;
  • des chiffres clés ;
  • les missions, présentées en cinq panneaux avec une image pour chacun ;
  • une chronologie des temps forts, filtrable mois par mois ;
  • un éditorial (mot du directeur) et des informations de contact.

Réalisation

Page unique en HTML, CSS et JavaScript, sans framework.

Dans le cadre du stage

Pendant ce stage, j'ai aussi créé des applications web pour les employés et appris Symfony.
